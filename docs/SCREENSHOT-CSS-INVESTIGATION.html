Root cause

Prior captures used static HTML files with incorrect relative CSS paths and an incomplete stylesheet stack. The real registration page loads 8+ CSS files via includes/pwa-head.php plus wizard/compact CSS. Unstyled screenshots validated markup only, not UX.

Fix

  • wizard-screenshot-preview.php - localhost-only preview with full production CSS stack over HTTP
  • scripts/capture-wizard-screenshots-styled.ps1 - PHP built-in server + Edge headless against http://127.0.0.1:8765/
  • Styled outputs: docs/screenshots/a4-verification/styled/{mobile,tablet,desktop}/
