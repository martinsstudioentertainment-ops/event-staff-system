6. Production safety layer (implemented)

Live production rules enforced: No downtime · no route changes · no permission changes · no DB deletions · no automatic file deletions · cleanup report before deploy · reversible via flags + backups.

6.1 Feature flags

File: includes/feature-flags.php
Admin UI: admin/feature-flags.php (Administrator only)
Storage: system_settings keys — no new tables

6.2 Cleanup audit (read-only)

File: includes/cleanup-audit.php
CLI: scripts/cleanup-audit.php (local only, not on server)
Reports: storage/reports/cleanup-{timestamp}.json, cleanup-latest.json
Admin UI: admin/cleanup-report.php

Scans: storage usage, large files (>5MB), old backups (>90d), duplicate CSS/JS hashes, empty directories, large logs. Never auto-deletes.

6.3 Deploy pipeline

[0/5] Pre-deploy backup (storage/backups/pre-deploy-*.zip)
[1/5] Cleanup audit (read-only)
[2/5] Git push
[3/5] FTP main admin
[4/5] FTP apply site

6.4 Rollback procedure

  1. Toggle feature flag OFF in admin → Feature flags
  2. Or restore storage/backups/pre-deploy-*.zip
  3. Or restore MySQL from admin → Backups
