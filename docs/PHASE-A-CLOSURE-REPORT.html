Rollback process

  1. Instant (no deploy): Admin → Feature flags → uncheck Registration wizard v2 → Save. Next page load serves legacy single-page form.
  2. Ops URL: GET /cron/wizard-flag-toggle.php?key=REMINDER_CRON_KEY&action=disable
  3. Verify rollback: powershell -File scripts\verify-wizard-production.ps1 expects data-wizard-mode="0"
  4. Data: No migrations — autosave is localStorage only; analytics files optional to archive
  5. Re-enable: Same paths with action=enable or checkbox ON
