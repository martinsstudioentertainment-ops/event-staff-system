5. Exact Rollback Plan

5.1 When to rollback

  • phase16-postcheck shows bad_count > 0 for orphan checks
  • Nick Cave registration counts changed unexpectedly
  • Admin staff list errors after migrate
  • FK migration fails mid-run

5.2 Rollback procedure (ordered)

LEVEL 1 — Partial (phase 48-51 only, data preserved)
  1. Run database/rollback-phase48-51.sql
  2. Note: MySQL 8.0.19+ supports DROP INDEX IF EXISTS; older: manual DROP
  3. Re-run phase16-postcheck
  4. Application continues — staff_id backfill from phase 49 REMAINS (beneficial)

LEVEL 2 — Full database restore (catastrophic)
  1. Maintenance mode ON (system_settings maintenance_mode=1)
  2. Restore MySQL dump from Step 1 backup via cPanel/phpMyAdmin
  3. Verify row counts match precheck baseline
  4. Maintenance mode OFF
  5. Smoke test Section 8

LEVEL 3 — PHP rollback (Phase 16b only)
  1. Revert includes/database-migrations.php from git/backup
  2. deploy.ps1
  3. No DB change needed if SQL not re-run

5.3 What rollback does NOT undo

migrate-phase49-backfill-staff-id.sql population of staff_id — intentional. Level 1 rollback does not clear staff_id. Level 2 full restore does.

6. Exact Backup Procedure

6.1 Pre-migration backup (mandatory)

PRODUCTION (admin.olasentra.com):
  1. Login → Admin → Settings → Backups
  2. Click "Run full backup now" (backup-run.php)
  3. Download all 3 weekly files from backups.php:
     - event-staff-database-*.sql
     - event-staff-settings-*.json
     - event-staff-site-*.zip
  4. Store locally: C:\Backups\olasentra\phase16-YYYYMMDD\

LOCAL (developer machine):
  powershell -ExecutionPolicy Bypass -File .\scripts\pre-deploy-backup.ps1
  → storage/backups/pre-deploy-YYYYMMDD-HHMMSS.zip

OPTIONAL cPanel:
  phpMyAdmin → event_staff_system → Export → SQL → Save

RECORD:
  - Backup timestamp
  - File sizes
  - phase16-precheck output
  - Git commit hash (if any)

6.2 Backup verification

  • SQL dump opens in text editor; contains CREATE TABLE staff
  • Dump size > 100 KB (production with data)
  • settings JSON contains site_name key
