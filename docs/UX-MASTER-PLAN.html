0. Design Philosophy

What we are building

Visual & interaction DNA

SourceWhat we take
Linear / RaycastKeyboard-first, command palette, minimal chrome, fast transitions
Stripe / VercelPrecise typography, status pills, dense data tables, dark command surfaces
Notion / AttioContext panels, inline properties, filterable views
Flight Control / Airport OpsEvent timeline, live status boards, amber/red alert hierarchy
Security Operations CenterMulti-panel dashboards, attention queues, operator roles

Ten design mandates

  1. Command, not browse — Every screen answers "what needs action now?"
  2. Event context is ambient — Global event selector persists; most views filter to it
  3. Density over decoration — 11–12px body, 32px row height tables, no wasted whitespace
  4. One inbox — Messages and alerts are one stream with filters
  5. Event Day Mode — Full-screen ops layout when live
  6. Palette over menus — Cmd+K for navigation and actions
  7. Progressive disclosure — 14 nav items max; depth via hubs and panels
  8. Role-native layouts — Manager, venue operator, admin see different command centers
  9. Status is colour + icon — Pending amber, approved green, live pulsing, critical red
  10. Mobile for staff, desktop for ops — PWA thumb-zone; admin is keyboard + wide screen

Event-scoped vs global mode

Header event selector toggles entire dashboard context. Global = all events aggregated. Event-scoped = single event ops board. Persisted in localStorage + URL ?event_id=.

4. Event Day Mode Blueprint

Full-screen operational mode activated automatically or manually when an event enters its live window (start_time − 2h → end_time + 1h).

Activation triggers

  • Auto: event date = today AND within time window
  • Manual: "Enter Live Ops" from Command Center or Event Hub
  • URL: live-ops.php?event_id=X

Layout: Flight-control split screen

9. Finance Blueprint

Finance is a post-event workspace, not daily ops. Single hub with tabs.

invoices.php (Finance Hub)
├── Tab: Commission Invoices    (commission_invoices)
├── Tab: Job Records            (saved_job_records)
├── Tab: Personal Invoices      (personal_invoice_lines)
└── Tab: Export Center          (all export-* linked)

Workflow

Event completes → Event Hub · Finance tab → Quick invoice from attendance hours
  → job-record-form (reference) → print-invoice → export-month

Density rules

  • Invoice list: 32px rows, inline status (draft/sent/paid/void)
  • Right drawer for invoice preview (not full page navigation)
  • EUR mono tabular numbers
