7. JavaScript behaviour

7.1 Step engine (registration-wizard.js)

  • Panels: .reg-wizard__step[data-step="N"] — only one visible
  • Navigation: Back / Continue; Enter key advances when valid
  • Per-step validators map to existing field IDs and error spans
  • Review step builds read-only summary from live DOM values
  • Edit links on review jump to step N without losing data
  • Preserves window.SERVER_FORM_ERRORS mapping on validation redirect

7.2 Shift picker integration

  • Reuse events.js unchanged — mount target remains #shift-picker-list
  • Wizard Step 2 shows picker immediately (no shift-gate lock in wizard mode)
  • registration-shift-gate.js checks data-wizard-mode="1" on body → skip lock UI
  • Server-side gate on submit unchanged

7.3 Returning registrant

  • Email step triggers existing lookup debounce
  • If found: true + profile_complete: prefill Steps 4–7, show "Welcome back" chip
  • If incomplete profile: banner + link to staff-profile.php
  • Auto-advance suggestion: complete profiles skip to Step 2 if events empty, else Step 8 review
