Phase 6 — Auto Approval Engine

Objective

Intelligent registration routing: auto-approve, manager review, incomplete, auto-reject.

Business value

Reduce manager workload 60% for repeat staff; faster roster fill; compliance gate automated.

Check pipeline (ordered)

  1. Blacklist → Auto Rejected
  2. Duplicate email+event → Auto Rejected
  3. Profile completion (staff.profile_completed) → Incomplete (hold)
  4. PSA validity (staff.psa_expiry_date) → Incomplete or Manager Review
  5. Event roles_needed match → Manager Review if mismatch
  6. Staff trust score < threshold (P7) → Manager Review
  7. All pass + trust ≥ Gold/Silver → Auto Approved

Files

New: includes/auto-approval-engine.php, includes/approval-rules.php, admin/approval-rules.php (settings UI)

Modify: submit.php (run engine post-insert), admin/update-status.php (log override), includes/staff-repository.php (bulk path), includes/notification-center.php (notify outcome)

Database

CREATE TABLE approval_rules (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  rule_key VARCHAR(50) NOT NULL UNIQUE,
  is_enabled TINYINT(1) DEFAULT 1,
  config_json JSON NULL,
  updated_at TIMESTAMP
);
CREATE TABLE approval_log (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  registration_id INT UNSIGNED NOT NULL,
  outcome ENUM('auto_approved','manager_review','incomplete','auto_rejected') NOT NULL,
  rule_results JSON NOT NULL,
  decided_by ENUM('system','admin') DEFAULT 'system',
  admin_user_id INT UNSIGNED NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_approval_reg (registration_id)
);

APIs

Testing

Trust score model

TierScore rangeCriteria weights

Silver70–84Same formula
Standard50–69Default new staff
