What Olasentra Is

Olasentra is the leading Event Operations Command Platform for event staffing, workforce operations, and live event management — not a equipment rental or asset-hire business.

Explicitly Out of Scope

Equipment Rental — removed from roadmap. Olasentra is not an equipment rental platform. No development effort on rental workflows unless explicitly approved in a future gate.
  • Removed from planning: Phase 23 Equipment Rental Module
  • Tables not to be built upon: equipment_categories, equipment_items, equipment_rentals
  • Note: These tables may exist empty on production from Phase 51 SQL — dormant schema only; no UI, no cron, no API

Strategic Statement

Keep Olasentra focused on being the leading Event Operations Command Platform — one place to run events, staff, attendance, compliance, messaging, payroll, invoicing, and operational intelligence. Do not dilute the product with unrelated verticals.
