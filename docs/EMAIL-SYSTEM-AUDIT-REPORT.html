10. Recommended fixes (documentation only — not applied)

  1. Confirm production uses SMTP (admin/settings-email.php) — required for reliable delivery on shared hosting.
  2. Encode Subject on PHP mail path — reuse smtpEncodeHeader() or always route through SMTP client.
  3. ASCII-safe punctuation option — replace — with - , – with -, · with | or , in email-specific formatters (mirrors Phase A3 wizard fix per PHASE-A3-OBSERVATIONS-LOG.html).
  4. Fix sendAdminAlertEmail() — sendEmail($pdo, $to, '[' . $siteName . '] ' . $subject, strip_tags($bodyHtml), $bodyHtml).
  5. Add HTML parts to E05, E06, E07 via buildStaffEmailHtmlFromLines().
  6. Consider multipart/alternative when both text and HTML exist.
  7. Normalize admin broadcast — strip/replace smart quotes in plainTextFromRich() / outbound HTML.
  8. Verification script — send each template to Gmail + Outlook test inboxes; grep raw source for =?UTF-8? in Subject and charset=UTF-8 in body.
