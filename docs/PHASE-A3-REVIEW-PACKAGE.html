5. Design review

Weak visual areas

  • Step 8 Review — grey placeholder box reads as incomplete product; primary visual on final step before submit.
  • Step 7 PSA file inputs — default browser file picker styling breaks visual consistency with rounded form inputs.
  • Progress dots — too subtle (4px bars); users rely on text “Step X of 8” only.
  • Shift selection heading — “Shift selection” vs nav label “Your gigs” — minor label inconsistency.

Empty space

  • Tablet/desktop gutters — 560px max-width centred in 768–1200px viewports leaves 30–54% unused horizontal space.
  • Step 5 Contact — single phone field with large vertical gap before nav; feels sparse.
  • Step 1 Welcome — trust chips + platform note + role select stack; acceptable on mobile, loose on desktop.
  • Below hero on desktop — could host a slim “How it works” visual without adding steps.

Typography issues

  • Form hints (0.72rem) — IBAN, DOB, PSA format hints may fail readability for 40+ demographic.
  • Profile card platform note — 0.72rem grey on purple tint — contrast borderline on some displays.
  • Section titles — form-section-title vs reg-wizard__step-name — two parallel labelling systems.
  • ALL CAPS metric labels on profile card — appropriate for KPI chips; ensure 0.68rem still legible.

Trust issues

  • Review step placeholder — undermines trust at highest-friction moment (submit).
  • Bank/payroll step — disclaimer present (A.2) but IBAN field still feels sensitive without lock icon or “encrypted” cue.
  • Platform disclaimer — correctly worded; repeated on shell + profile card (acceptable for compliance).
  • Privacy consent block — legally sound; dense paragraph may reduce tick rate on mobile.

Mobile improvements (recommended for A.4+)

  • Collapse gender radios to 2×2 grid on wider phones to cut Step 4 scroll.
  • Add camera capture hint on PSA uploads (“Use phone camera — front of card”).
  • Sticky “Step X of 8” mini-bar when scrolling long steps.
  • Increase progress dot hit area or replace with numbered pills.
  • Build real review summary (A.4 scope) — highest conversion impact.
