4. User flow

  1. Step 1 Welcome — If draft in localStorage → Resume Application / Start New Application
  2. Step 3 Email — Debounced lookup → Welcome Back profile card + smart prefill (steps 4–7 fields)
  3. Step 2 Events — Registered IDs from lookup → cards show Already Registered (disabled)
  4. Complete profile — “Pick new events” CTA jumps to Step 2 (one tap)

6. Verification checklist

  • Flag OFF — legacy form + returning-registrant.js unchanged
  • Flag ON — known email shows Welcome Back card with all metrics
  • Edit a field → re-lookup does not overwrite
  • Draft → Resume Application restores step; Start New Application clears draft + analytics
  • Registered event tap → Already Registered tip + duplicate_application_prevented
  • Admin dashboard → Registration funnel → Returning user flow KPIs

7. Rollback

Turn feature_registration_wizard_v2 OFF in admin Feature Flags. Legacy registration restores immediately. Optional: clear olasentra_reg_wizard_* localStorage keys on client devices.
