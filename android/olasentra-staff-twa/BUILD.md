# Olasentra Staff — Android TWA build guide

This project wraps the **live** staff platform at `https://register.olasentra.com/staff-app.php`.
No second backend or database.

## Prerequisites

1. [Android Studio](https://developer.android.com/studio) (Ladybug or newer)
2. JDK 17+
3. Google Play upload keystore (create once, keep offline backup)

## One-time setup

```powershell
# From repo root — copy branded icons into Android mipmaps
powershell -ExecutionPolicy Bypass -File .\android\olasentra-staff-twa\scripts\copy-launcher-icons.ps1

# Create upload keystore (store passwords securely)
keytool -genkeypair -v -keystore android/olasentra-staff-twa/keystore/upload-keystore.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000

# Copy signing config
copy android\olasentra-staff-twa\signing.properties.example android\olasentra-staff-twa\signing.properties
# Edit signing.properties with your passwords
```

## Digital Asset Links (required before Play review)

1. Get SHA-256 fingerprint of your **upload** certificate:

```bash
keytool -list -v -keystore keystore/upload-keystore.jks -alias upload
```

2. Replace `REPLACE_WITH_UPLOAD_KEY_SHA256_FINGERPRINT` in:

`/.well-known/assetlinks.json`

3. Deploy `assetlinks.json` to production (`register.olasentra.com`).

4. Verify: https://digitalassetlinks.googleapis.com/v1/statements:list?source.web.site=https://register.olasentra.com&relation=delegate_permission/common.handle_all_urls

## Build release AAB (Google Play)

Open `android/olasentra-staff-twa` in Android Studio, then:

**Build → Generate Signed Bundle / APK → Android App Bundle → release**

Or from project directory (after Gradle wrapper is generated by Android Studio):

```bash
./gradlew bundleRelease
```

Output: `app/build/outputs/bundle/release/app-release.aab`

## What the TWA preserves

- Google Sign-In (HTTPS OAuth callback on same host)
- GPS sign-in (`ACCESS_FINE_LOCATION` declared)
- QR / venue URLs opened in Chrome Custom Tabs scope
- Web Push (Chrome engine inside TWA)
- All payroll, events, and admin systems unchanged on server
