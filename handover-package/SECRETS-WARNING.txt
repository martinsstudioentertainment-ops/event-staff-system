SECURITY WARNING
================

The folder "local-secrets" contains passwords and API keys:

  - FTP password (deploy.local.ps1)
  - Database credentials (config.php, database.php)
  - Google service account (service-account.json)
  - Firebase config (google-services.json)

DO NOT:
  - Upload this folder to public GitHub
  - Email unencrypted
  - Share on public cloud without encryption

DO:
  - Copy to your new PC via USB or encrypted cloud
  - Delete from shared computers when no longer needed
  - Keep deploy.local.ps1 gitignored on the new machine

When restoring on new PC, copy files from local-secrets\ back to paths
listed in SETUP-NEW-PC.txt
