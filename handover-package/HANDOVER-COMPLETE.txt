1. EXECUTIVE SUMMARY
================================================================================

Olasentra (formerly "Event Staff System") is a PHP/MySQL staff management
platform for event security staffing in Ireland. It handles:

  - Public marketing site
  - Staff registration (Google Sign-In)
  - Staff web app / PWA (dashboard, shifts, GPS check-in)
  - Admin ERP (events, staff directory, attendance, payroll, comms hub)
  - Apply portal (apply.olasentra.com)
  - Native Android staff app (Kotlin/Compose, v1.0.15)
  - Mobile REST API (register.olasentra.com/api/mobile/v1)
  - Email OTP sign-in (Gmail and non-Gmail staff)
  - Google Sheets sync, email notifications, WhatsApp group links

Production is hosted on cPanel (FTP) with one shared MySQL database.
Code is on GitHub; deploy = git push + FTP upload.

Status as of 14 June 2026 (evening):
  - Production verified (35/35 staff probe checks passed)
  - Mobile API enabled, Google sign-in enabled, email OTP enabled, GPS v2 enabled
  - Branding updated (purple shield "O" logo) on web, WhatsApp, PWA, mobile
  - Android APK v1.0.15 live (Master UI, email OTP, Settings, high-contrast auth)
  - Payroll tile hidden in Android app + admin sidebar (backend payroll preserved)
  - Local workspace has many uncommitted changes (deployed via FTP + APK deploy script)
