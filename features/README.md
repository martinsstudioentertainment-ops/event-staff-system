# Features

Feature-flagged additions that span UI + backend.

## Guidelines

- Gate with `isFeatureEnabled()` or admin settings
- Pair UI and API in `scripts/deploy-ui-api-manifest.json`
- Add health check when the feature affects operations
- See `docs/V1.1-EXTENSION-GUIDE.md`

## v1.1 target examples

- Studio booking enhancements
- Equipment rental improvements
- Reporting and analytics
- Branding and customization tools
